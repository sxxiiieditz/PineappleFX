Install & activate

Five minutes, once.

1. Enable debug mode

Run once as admin: reg add HKCU\Software\Adobe\CSXS.11 /v PlayerDebugMode /t REG_SZ /d 1 /f

2. Install the .zxp

Open it with an extension manager, or copy the folder to %APPDATA%\Adobe\CEP\extensions\. Use the personal .zxp from your purchase email (it comes pre-activated for your machine)

3. Copy your Machine ID

Restart After Effects, open Window - Extensions - PineappleFX. Click the Machine ID to copy it.

4. Activate

Paste the key from your email into the panel. Done - works offline from here on.
